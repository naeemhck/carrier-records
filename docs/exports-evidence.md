## Implemented behavior

Full exports revalidate account, office, recipient, preset and selected fields on the server, retrieve every authorized page coherently and keep canonical totals independent of presentation. Immutable issued documents are fetched under current authority and verified against their canonical digest before generation. The renderer serializes approved metadata and selected values only. PDF and Excel generation run in compute isolates. Windows save/share/print actions are connected to current previews and issued views; each action fetches fresh authority and reports success only after its destination confirms.

A4 PDF automatically chooses orientation, supports explicit overrides, splits wide attributes in stable order, wraps long text, repeats headings, includes source-row references/continuation markers, minimum 9 pt text, required metadata, canonical summaries and page numbers. Excel has one visible sheet, exact decimal XML values, explicit safe inline text, selected-order headings, scope/date bases, currency/date formatting, wrapping, frozen headings, filtering and repeated print titles. Money beyond Excel's 15-significant-digit precision is preserved as text with a visible explanation. Printing uses fixed PDF bytes, not a calculation based on printer dimensions.

## Failures investigated and corrected

The first synthetic recipient label exceeded the documented master-label limit; the fixture was reduced to 119 characters. Initial visual QA exposed a narrow Row heading, mid-word continuation splitting and empty continuation pages; the row header width, word-boundary chunking and per-section empty-continuation filtering were corrected, then actual files regenerated. The first independent inspection expected HYPERLINK in an owner field unavailable to that recipient; it now checks formula-like text only when present in selected source values. PDF order checking initially confused a short label with the prefix of another label; it now verifies contiguous ordered table headings. New action tests initially assumed desktop success wording while Flutter's test platform was Android, then used an override not restored before framework invariant checks; expectations now follow the platform without global overrides. Analyzer findings in those tests were fixed before the clean analyzer/test run.

A first full regression after reset stopped during the T06 password-change call while the local Edge container restarted; synthetic cleanup passed. The endpoint subsequently returned its expected unauthorized response, with no duplicate serve process. The full suite was rerun after runtime recovery. HTTP status diagnostics now expose only status numbers, never credentials.
