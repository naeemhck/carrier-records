# Carrier Records client

Windows-first Flutter client with an Android runner. T01 currently provides only the application harness and setup screen; accounts and financial workflows follow the ordered backlog.

See [development tooling](../docs/tooling.md), [verification evidence](../docs/tooling-evidence.md), and [tasks](../tasks.md). Run commands from this directory using `../tools/flutter.ps1` or the existing configured Flutter SDK.
